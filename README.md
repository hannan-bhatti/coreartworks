# Core Artworks | Digital Arts & Visual Production Agency

A high-performance, responsive web application for **Core Artworks** built with **React 18 + Vite + TypeScript + Tailwind CSS**.

## ✨ Key Features

1. **Monochrome Luxury Design System**:
   - Grey, White, and Black editorial aesthetic with ambient glow effects, glassmorphic cards, and high-contrast typography (`Cinzel`, `Space Grotesk`, `Syne`, `Inter`).
2. **5 Core Digital Art Disciplines & 21 Subcategories**:
   - **Concept Art & VisDev**: Environment Design, Character Concepts, Keyframes, Vehicles/Mechs, Creature Design.
   - **3D Production & Sculpting**: High-Poly Digital Sculpting, Character Modeling, Hard Surface Game Assets, Procedural Environments.
   - **2D & Editorial Illustration**: Key & Splash Art, Card Game & TCG Art, Graphic Novels/Storyboards, Promotional Murals.
   - **Motion, VFX & Animation**: Cinematic VFX, Character Animation, Stylized Motion Graphics, Unreal Engine 5 Real-Time.
   - **Brand Identity & Game UI/UX**: Diegetic HUDs, Studio Branding, Worldbuilding Art Bibles, Merch Packaging.
3. **Interactive Experience Enhancers**:
   - **Interactive Before/After Inspector**: Split-screen draggable slider comparing raw sketches/clay models with the final polished render.
   - **High-Res Lightbox Inspector**: Fullscreen inspection with color palette hex extraction (click to copy), tools used, client metadata, and instant quote jump.
   - **Commission & Project Cost Estimator**: Real-time deterministic pricing calculator taking into account discipline, fidelity tier, turnaround sprint, and IP buyout.
   - **Interactive Testimonials**: Verified client reviews from Game Producers and Art Directors.
   - **Searchable FAQ Accordion**: Instant search across licensing, NDA policies, and deliverables.
   - **Creative Brief Intake Form**: Validated submission with budget/scope pre-filling and confetti confirmation.
   - **Socials**: Links for Instagram, DeviantArt, ArtStation, Discord, and GitHub.

## 🛠️ Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```

## 🚀 Deploy to GitHub & Vercel

### Option 1: Git & GitHub
```bash
git init
git add .
git commit -m "feat: initial Core Artworks website build"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/core-artworks-website.git
git push -u origin main
```

### Option 2: Deploy to Vercel
1. Push to GitHub.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import the repository.
4. Framework preset will automatically detect **Vite**.
5. Click **Deploy**.
